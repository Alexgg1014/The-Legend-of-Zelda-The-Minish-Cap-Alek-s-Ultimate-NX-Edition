# Alek's Ultimate NX Edition v1.4.16

Saves and settings carry over; the in-app updater installs it as usual (copy
`tmc_aleks_ultimate_nx.nro` to `/switch/tmc/` as is if installing by hand).

## Added

- **Assign items to X / Y / ZL / ZR from the game's own inventory.** Open the
  pause screen, highlight an item and press X, Y, ZL or ZR: it goes on that
  button, exactly the way A and B work in vanilla. The second screen's ITEMS
  tab still does the same thing, and both views show the same assignment.
  Suggested by @lbsbezerra (issue #13).

  The other half of that request — drawing the X/Y buttons in the in-game HUD —
  is not in: that HUD is the GBA's own, built from the game's tiles and already
  re-anchored for widescreen, so it needs artwork and render work rather than a
  hook. Still on the list.
